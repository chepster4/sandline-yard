SANDLINE YARD is a round-based tactical FPS in three.js: two teams of five fight over two bomb sites in a desert-dusk foundry yard. Plant or defuse the bomb, win rounds, earn money, and spend it between rounds on rifles, SMGs, snipers, grenades and armour. Nine bots with skill tiers (rookie, veteran, elite), callouts, real line-of-sight vision, hearing, burst fire, strafing and bomb roles play the other side — they hold angles, rotate to a plant, retrieve a dropped bomb and defuse under fire, and the carrier attacks the site the defence left thinnest. Spectate fallen teammates with C, cycle weapons with the mouse wheel, and watch the round pips fill toward eight. No build step, no network requests: static files, procedural WebAudio sound, vendored three.js 0.187.0.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser with WebGL 2.
